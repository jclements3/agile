Title: Can every course be finished?
LeetCode: 207. Course Schedule (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: topological sort (Kahn), cycle detection
Timebox: 15
Kind: function
Call: can_finish($n, \@prereqs) -> 1 | 0

Courses are numbered 0 .. n-1. Each prerequisite [a, b] means b must be taken
before a. Return true when some order takes every course, false when the
prerequisites contain a cycle.

Examples
  can_finish(2, [[1, 0]])          ->  true
  can_finish(2, [[1, 0], [0, 1]])  ->  false
  can_finish(3, [])                ->  true
