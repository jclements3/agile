Title: Fewest removals to stop overlaps
LeetCode: 435. Non-overlapping Intervals (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: greedy: keep the interval that ends first
Timebox: 15
Kind: function
Call: erase_overlaps(\@intervals) -> $count

Return the smallest number of intervals to delete so that the rest do not
overlap. Here intervals that only touch ([1, 2] and [2, 3]) do not overlap.

Examples
  erase_overlaps([[1, 2], [2, 3], [3, 4], [1, 3]])  ->  1
  erase_overlaps([[1, 2], [1, 2], [1, 2]])          ->  2
  erase_overlaps([])                                ->  0
