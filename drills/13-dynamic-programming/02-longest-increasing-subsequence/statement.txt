Title: Longest increasing subsequence
LeetCode: 300. Longest Increasing Subsequence (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: dp[i] = longest run ending at i
Timebox: 15
Kind: function
Call: lis(\@nums) -> $n

Return the length of the longest strictly increasing subsequence: values in
their original order, not necessarily next to each other. Equal values do
not count as increasing. An empty list gives 0.

Examples
  lis([3, 1, 8, 2, 5, 9])  ->  4   (1, 2, 5, 9)
  lis([7, 7, 7])           ->  1
  lis([])                  ->  0
