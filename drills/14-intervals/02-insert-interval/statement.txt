Title: Insert an interval
LeetCode: 57. Insert Interval (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: three phases: before, overlapping, after
Timebox: 15
Kind: function
Call: insert_interval(\@intervals, \@new) -> [[s, e], ...]

@intervals is sorted by start and non-overlapping. Insert @new ([start,
end]), merging it with every interval it overlaps or touches, and return the
list, still sorted and non-overlapping.

Examples
  insert_interval([[1, 3], [6, 9]], [2, 5])  ->  [[1, 5], [6, 9]]
  insert_interval([], [4, 8])                ->  [[4, 8]]
