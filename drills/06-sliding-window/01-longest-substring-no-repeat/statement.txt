Title: Longest substring without a repeat
LeetCode: 3. Longest Substring Without Repeating Characters (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: sliding window with last-seen positions
Timebox: 15
Kind: function
Call: longest_no_repeat($s) -> $length

Return the length of the longest contiguous piece of $s in which no character
appears twice. O(n).

Examples
  longest_no_repeat('pwwkew')  ->  3     ('wke')
  longest_no_repeat('')        ->  0
  longest_no_repeat('abba')    ->  2
