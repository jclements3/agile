Title: Maximum of every window
LeetCode: 239. Sliding Window Maximum (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: monotonic deque of indices
Timebox: 25
Kind: function
Call: max_sliding_window(\@nums, $k) -> [...]

For every contiguous window of $k elements of @nums, from left to right,
return the window's maximum. There are n - k + 1 windows. O(n), not O(n k).

Constraints: 1 <= k <= n.

Examples
  max_sliding_window([4, 2, 12, 3, 8, 1], 3)  ->  [12, 12, 12, 8]
  max_sliding_window([5, 6], 1)               ->  [5, 6]
