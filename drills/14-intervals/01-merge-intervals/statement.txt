Title: Merge overlapping intervals
LeetCode: 56. Merge Intervals (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: sort by start, fold overlapping runs
Timebox: 15
Kind: function
Call: merge_intervals(\@intervals) -> [[s, e], ...]

Each interval is [start, end] with start <= end, inclusive, in any order.
Merge every group that overlaps or touches ([1, 3] and [3, 5] become [1, 5])
and return the result sorted by start. An empty list gives [].

Examples
  merge_intervals([[8, 9], [1, 4], [2, 5]])  ->  [[1, 5], [8, 9]]
  merge_intervals([[1, 3], [3, 4]])          ->  [[1, 4]]
