Title: No two neighbours
LeetCode: 198. House Robber (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: take-or-skip, two running values
Timebox: 10
Kind: function
Call: rob(\@values) -> $best

Pick values from the list so that no two picked values are next to each
other, maximising their sum. Values are non-negative. Return the best sum
(0 for an empty list).

Examples
  rob([2, 7, 9, 3, 1])  ->  12   (2 + 9 + 1)
  rob([5])              ->  5
