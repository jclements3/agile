Title: Lowest common ancestor in a BST
LeetCode: 235. Lowest Common Ancestor of a Binary Search Tree (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: walk down to the split point
Timebox: 10
Kind: function
Call: lowest_common_ancestor($root, $p, $q) -> $node

The tree is a binary search tree; $p and $q are two of its nodes. Return the
deepest node that has both in its subtree (a node is in its own subtree).
Use the ordering: no need to search both sides.

Examples (by value)
  BST [6, 2, 8, 0, 4, 7, 9], p 2, q 8  ->  6
  same tree, p 2, q 4                  ->  2
