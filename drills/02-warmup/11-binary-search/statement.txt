Title: Binary search
LeetCode: 704. Binary Search (a pointer only: the statement below is this kit's own)
Origin: warmup
Pattern: lo/hi loop on sorted data
Timebox: 5
Kind: function
Call: binary_search(\@sorted, $target) -> $index | -1

The list is sorted ascending with no duplicates. Return the index of $target,
or -1 when it is absent. Write the loop yourself: no scan, no grep.

Examples
  binary_search([1, 3, 5, 7], 5)  ->  2
  binary_search([1, 3], 2)        ->  -1
  binary_search([], 1)            ->  -1
