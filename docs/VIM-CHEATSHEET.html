Vim cheatsheet for the kit

Everything here runs in the Vim that ships with Git for Windows (Git Bash: vim), nothing to install. \ is the leader key, so \sn means press \ then s n. Vim's own help: :help, and vimtutor in Git Bash is a 30-minute hands-on lesson.

One-time setup

echo 'syntax on'                                         >> ~/.vimrc
echo 'source ~/projects/agile/vim/scrum.vim'             >> ~/.vimrc   # your clone's path
echo "let g:markdown_fenced_languages = ['idef0']"       >> ~/.vimrc   # colour ```idef0 blocks in .md models

That one source line turns on every mode below: the file types are recognised by name, so opening a file picks its mode. Check with :set ft?.

Help, offline

:help agilethe kit's help: runbooks, commands, verbs, scrum.conf keys
:help :STown :help \swany :S/:Idef/:Sys command or \s/\i/\m key by name
:help agile-howto"How do I...?": the runbooks

Vim's modes, in one breath

EscNormal mode: move and command. When in doubt, press Esc.
i a oInsert: before cursor / after cursor / new line below (O above)
v V Ctrl-vVisual: characters / lines / a block (columns)
:Command line: :w save, :q quit, :wq, :q! quit without saving
u Ctrl-rundo / redo
.repeat the last change

Move

h j k lleft, down, up, right
w b enext word / back a word / end of word
0 ^ $line start / first non-blank / line end
gg G 42Gtop / bottom / line 42
Ctrl-d Ctrl-uhalf a page down / up
% matching bracket
* #next / previous use of the word under the cursor (a task id, a flow name)
Ctrl-o Ctrl-iback / forward through where you have been

Edit

x dd yy pdelete char / delete line / copy line / paste below
dw cw ciwdelete word / change word / change the whole word under the cursor
cc C Dchange line / change to end / delete to end
>> <<indent / outdent a line (in Visual: the selection). IDEF0 nesting is indentation
Jjoin the next line onto this one
Ctrl-n(Insert) complete a word from open files; in stand-ups, task ids from the journal
:'<,'>norm I; comment out the selected lines (puts ; before each)

Search and replace

/text n Nsearch forward, next, previous (?text searches back)
:%s/old/new/greplace everywhere; add c to confirm each
:nohclear the search highlight
:vimgrep /HAL-12/ **/*.txtsearch files; results in the quickfix list (:cw)

Windows, tabs, buffers

:sp :vssplit across / side by side (with a file name: open it there)
Ctrl-w h j k lmove to the window left, down, up, right
Ctrl-w o Ctrl-w conly this window / close this window
:tabnew gt gTnew tab / next tab / previous tab
:e file :ls :b 3open / list open files / switch to buffer 3
:e!reload from disk, dropping changes (after a tool rewrote the file)

Clipboard (Windows)

"+ppaste from the Windows clipboard (Teams chat, Outlook, Word)
"+yy "+ycopy a line / the selection to the Windows clipboard
:%y+copy the whole file to the clipboard

Folds and the quickfix list

za zc zotoggle / close / open the fold under the cursor
zM zRclose all / open all
:cw :cn :cpshow the error list / next error / previous error
Enter(in the list) jump to that file and line

Run a tool

:!cmdrun a shell command; % is this file: :!perl tools/memo/md2memo.pl % > memo.pdf
:r !cmdinsert a command's output here (:r !date +\%F)
:'<,'>!sortfilter the selected lines through a command
:terminala Git Bash shell in a Vim window

The kit's modes

The \s… keys and :S… commands work in any buffer inside a project (they find scrum.conf upward from the file). The \i… keys work only in an IDEF0 buffer.

Stand-up notes — standups/YYYY-MM-DD.txt

\sn :SNew [Team]today's file, one section per team, the open items listed
Ctrl-n(Insert) complete a task id from the journal
\sd :SDrysave, then show what compile would write
\sc :SCompilesave, then compile today's notes into the journal
\ss :SStatustoday at a glance
\sa :SAllsave, compile, report, draft the mail
:SCommit :STigcommit the project / browse its git history
2026-10-05
sprint 1
== Halberd
cap 320
new HAL-1 21 "Port 21 v1 items" e:"E Systems Engineering" o:JC
commit HAL-1 JC
done HAL-1                      ; one verb per line; ; starts a comment
carry HAL-2
block HAL-3 waiting on the shared runner
unblock HAL-3
note Interceptor Development is gated on every merge

Also: hold/resume, punt, redo, pass ID Team, sync ID ID, est, assign, risk, absent. The full list is the header of lib/Standup.pm.

\sr :SReportrebuild the reports

Coding drills — :DrillTrain, drills/

:DrillTrain [N]the memory trainer: type each solution from memory as the hint fades; a perfect level unlocks the next
\dc :DrillAnswercheck the answer (Ctrl-G Ctrl-G in insert mode)
\dg :DrillGiveUpshow the solution (a miss on the blind rep)
\dn Spacecontinue after a miss or a level result
\dl :DrillLevel [N] \drchoose an unlocked level; replay this one
\dq :DrillQuit :DrillResetleave (progress is saved); forget the progress
\do :DrillOpenstatement ↔ your file in ~/drills-work (made, clock started, the first time)
\dt :DrillTest \da :DrillTestAlldrill.pl test this problem; check everything you have
perl drills/drill.pl next          the next problem   start ID / test ID / solution ID / log

The 90-day routine is docs/DRILLS.html; :help agile-drills.

IDEF0 models — *.idef0, *.txt with a modeline, ```idef0 in .md

\il :IdefLintlint this file; errors go to the quickfix list (:cn)
\iL :IdefLintProjectlint every model in this directory (links resolve across files)
\iv :IdefPlatesthe project's plates as text, in a split
\id :IdefDumpthe numbered node tree
\ik :IdefLinksthe interface table
\in :IdefNumberfmt --number: freeze derived numbers into the tags
\iu :IdefAutofmt --auto: back to # (models keep their letter)
\if :IdefFollowjump to the target of this line's </> link
\ionew sibling line below (same indent and tag), in Insert
za zc zofold a subtree (folds follow the indentation); Tab indents by 2 spaces
# -*- mode: idef0 -*-        a .txt is a model when line 1 says so
tD Design                    t model (letter D)
  a# Define Quad Spec        a activity; nesting by 2 spaces
    i# Pilot Requirements    i input  c control  o output  m mechanism
    o# Quad Spec > F|Cut Frame Parts|Quad Spec      > feeds, < fed by
    ## doc comment           # or ; comment

Outside Vim: tools/idef0/idef0lint, idef2html, idef2svg; see tools/idef0/README.md. The Emacs twin is tools/idef0/idef0-mode.el.

SysML v2 models — *.sysml, *.kerml

\ml :SysLintlint the whole model (the project is the nearest folder up holding model/); errors to the quickfix list
\mk :SysCheckthe 2..9 outline rule and the @L level tags
\mx :SysSyntaxthis file against the official SysML v2 grammar
\mv :SysValidatefull compile with the Pilot engine (only where Java is installed)
\md :SysDocsregenerate docs/: nouns, verbs, IDEF0, traceability
\mr :SysTracerequirement → satisfied by → verified by, in a split
\mn \mb :SysNouns :SysVerbsthe part tree / the function tree
\mt :SysTagsbuild the tags file; then Ctrl-] on a name or DOORS id, Ctrl-t back
:make lint|check|validatethe same through Vim's compiler (outside a project: sysml.pl check %)

Porting SysML v1 and DOORS to v2
