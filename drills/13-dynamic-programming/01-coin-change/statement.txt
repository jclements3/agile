Title: Fewest coins
LeetCode: 322. Coin Change (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: bottom-up table: fewest coins per amount
Timebox: 15
Kind: function
Call: coin_change(\@coins, $amount) -> $n

Each coin value may be used any number of times. Return the fewest coins
whose values add up to exactly $amount, or -1 when no combination does.
Amount 0 needs 0 coins. Greedy (largest coin first) is not always right.

Examples
  coin_change([1, 2, 5], 11)  ->  3   (5 + 5 + 1)
  coin_change([1, 3, 4], 6)   ->  2   (3 + 3, not 4 + 1 + 1)
  coin_change([2], 3)         ->  -1
