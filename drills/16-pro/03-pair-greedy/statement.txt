Title: Pair values within a tolerance
LeetCode: none (an original problem)
Origin: lessons
Pattern: build candidates, sort, take greedily
Timebox: 15
Kind: function
Call: pair_greedy(\@a, \@b, tol => $tol) -> [[a, b], ...]

Pair numbers from @a with numbers from @b whose difference is at most $tol.
Take the closest candidate pairs first, each value used at most once; break
exact ties by index in @a, then index in @b. Return the pairs [a_value,
b_value] sorted by a_value ([] when none).

Examples
  pair_greedy([10, 20], [10.1, 19.8, 50], tol => 0.5)  ->  [[10, 10.1], [20, 19.8]]
  pair_greedy([1], [5], tol => 0.5)                    ->  []
