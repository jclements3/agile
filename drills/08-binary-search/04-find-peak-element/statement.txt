Title: Find a peak
LeetCode: 162. Find Peak Element (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: binary search toward the higher neighbour
Timebox: 15
Kind: function
Call: find_peak(\@nums) -> $index

A peak is an element strictly greater than its neighbours; positions outside
the list count as minus infinity, and neighbours are never equal. Return the
index of any peak in O(log n).

Examples
  find_peak([1, 3, 2])        ->  1
  find_peak([1, 2, 1, 3, 1])  ->  1 or 3
  find_peak([5])              ->  0
