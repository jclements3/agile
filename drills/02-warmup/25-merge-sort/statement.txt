Title: Merge sort by hand
LeetCode: 912. Sort an Array (a pointer only: the statement below is this kit's own)
Origin: warmup
Pattern: divide and conquer, then a two-pointer merge
Timebox: 10
Kind: function
Call: merge_sort(\@xs) -> [ sorted ]

Return a new list with the numbers in ascending order, without calling sort.
Split in half, sort each half recursively, merge the two sorted halves.
Do not change the input.

Examples
  merge_sort([5, 2, 8, 1])  ->  [1, 2, 5, 8]
  merge_sort([3, 3, 1])     ->  [1, 3, 3]
  merge_sort([])            ->  []
