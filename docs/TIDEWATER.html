Tidewater: MBSE in GitLab, sprint by sprint

Tidewater is fictional, civilian and notional, and so is every number here. Three government systems engineers, Jim, Bob and Tom, port a prime contractor's SysML v1 model of a coastal weather-observation network to SysML v2 text in GitLab, then keep it current with the prime's drops. This page covers sprints 1–6 (from 5 October 2026). Every number on it is read from the evidence in docs/tidewater/, which a run of the kit produced: the GitLab emulator, the pipeline, gitflow, the converters, the journal. The book MBSE-DEVSECOPS Primer tells these weeks; docs/tidewater/README.md lists every evidence file.

perl sim/tidewater-sim.pl --dir RUN/data/tidewater --sprints 6 --no-docs   # the run
perl sim/tidewater-evidence.pl RUN/data/tidewater                           # its evidence into docs/tidewater/
perl sim/tidewater-render.pl                                                # this page
