Title: To Roman numerals
LeetCode: 12. Integer to Roman (a pointer only: the statement below is this kit's own)
Origin: warmup
Pattern: greedy over a value table
Timebox: 6
Kind: function
Call: to_roman($n) -> $numeral

Write 1 <= n <= 3999 as a Roman numeral. Use the subtractive forms: 4 is IV,
9 is IX, 40 is XL, 90 is XC, 400 is CD, 900 is CM.

Examples
  to_roman(1994)  ->  "MCMXCIV"
  to_roman(58)    ->  "LVIII"
  to_roman(9)     ->  "IX"
