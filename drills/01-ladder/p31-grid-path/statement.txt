Title: Shortest path in a grid
LeetCode: 1091. Shortest Path in Binary Matrix (similar; a pointer only: the statement below is this kit's own)
Origin: ladder
Pattern: breadth-first search
Timebox: 20
Kind: stdio

Input: line 1 is "R C"; then R rows of '.' (open) and '#' (wall).
Output: the fewest up/down/left/right steps from the top-left cell to the
bottom-right cell, or -1 if there is no path (also when either end is a
wall). A 1x1 open grid needs 0 steps.

Examples
  1 3 / ...      ->  2
  2 2 / .# / ##  ->  -1
