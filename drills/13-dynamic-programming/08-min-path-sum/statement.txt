Title: Cheapest path down and right
LeetCode: 64. Minimum Path Sum (a pointer only: the statement below is this kit's own)
Origin: lessons
Pattern: grid DP: cheapest way to reach each cell
Timebox: 15
Kind: function
Call: min_path_sum(\@grid) -> $cost

@grid is an array ref of rows of non-negative costs. Moving only right or
down from the top-left cell to the bottom-right cell, return the smallest
total cost of the cells visited, both ends included.

Examples
  min_path_sum([[1, 3, 1], [1, 5, 1], [4, 2, 1]])  ->  7
  min_path_sum([[5]])                              ->  5
