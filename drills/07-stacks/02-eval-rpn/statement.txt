Title: Evaluate postfix notation
LeetCode: 150. Evaluate Reverse Polish Notation (a pointer only: the statement below is this kit's own)
Origin: technique
Pattern: stack machine
Timebox: 10
Kind: function
Call: eval_rpn(\@tokens) -> $value

@tokens is a valid postfix expression: integers and the operators + - * /.
An operator applies to the two values before it (the earlier one on the left).
Division truncates toward zero. Return the value.

Examples
  eval_rpn(['3', '4', '+', '2', '*'])  ->  14
  eval_rpn(['7', '-2', '/'])           ->  -3
