Title: Pascal's triangle
LeetCode: 118. Pascal's Triangle (a pointer only: the statement below is this kit's own)
Origin: warmup
Pattern: build each row from the previous one
Timebox: 5
Kind: function
Call: pascal($n) -> [ [1], [1, 1], ... ]

Return the first n rows of Pascal's triangle. Each row starts and ends with 1;
every inner value is the sum of the two values above it.

Examples
  pascal(4)  ->  [[1], [1, 1], [1, 2, 1], [1, 3, 3, 1]]
  pascal(0)  ->  []
