Title: Common elements, in order
LeetCode: none (an original problem)
Origin: lessons
Pattern: hash for membership, hash for seen
Timebox: 4
Kind: function
Call: common_ordered(\@a, \@b) -> [ ... ]

Return the elements of @a that also occur in @b, in @a's order, each at
most once.

Examples
  common_ordered([1, 2, 3, 4], [3, 1, 5])  ->  [1, 3]
  common_ordered([1, 1, 2], [1])           ->  [1]
  common_ordered([1, 2], [3])              ->  []
