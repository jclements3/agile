Laptop test plan — Calendar.pm against real Outlook/Teams

Everything above the COM layer is tested offline (tests/calendar.t, 75 tests; tests/standup.t covers daily.pl attend/post on the mock). This session verifies the one untested layer: PowerShell + Outlook COM on the target Windows machine. Budget 30 minutes. Do it in this order; each step isolates one thing.

0. Baseline (2 min)

cd ~/tools/agile && for t in tests/*.t; do perl $t | tail -1; done       # all pass on Git Bash Perl?
powershell.exe -NoProfile -Command '$PSVersionTable.PSVersion; Get-ExecutionPolicy -List'

Note the version. -EncodedCommand is used, so execution policy should not matter; if powershell.exe itself is blocked by AppLocker, stop here — the calendar layer needs another route (Excel VBA/Outlook VBA are the fallbacks).

1. COM reachable (3 min)

powershell.exe -NoProfile -Command '$o = New-Object -ComObject Outlook.Application; $o.Version; $o.GetNamespace("MAPI").GetDefaultFolder(9).Items.Count'

Expect a version and an item count. Failures here are environment (Outlook not running as the same user, COM blocked, "new Outlook" instead of classic — the new Outlook has no COM, use classic).

2. Round trip (5 min)

perl bin/cal.pl list                    # today
perl bin/cal.pl list --from 2026-09-22 --to 2026-09-26

Check: stand-ups appear, times are local, recurring ones expand, attendee counts look right, "Teams" shows on Teams meetings. Then keep a fixture for offline work:

perl bin/cal.pl dump --from 2026-09-22 --to 2026-09-26 > examples/cal-real.json

(review it before committing anywhere; it contains names and e-mail addresses)

What to fix if it fails, all in lib/Calendar.pm near the bottom:

  • JSON errors / nothing listed: run perl bin/cal.pl ps > /tmp/x.ps1, then powershell.exe -NoProfile -File /tmp/x.ps1 to see the raw error.
  • Empty list but Outlook shows meetings: _psdate — Restrict wants the machine locale's date format; en-US MM/dd/yyyy is assumed. Try Get-Culture and adjust.
  • Teams meetings not flagged: _norm_event teams detection (body link or location text).
  • Odd characters in names: the UTF-8 console setting at the top of the script.

3. Attendance (5 min)

perl bin/cal.pl attend stand
perl bin/daily.pl attend            # from the scrum project dir

Check names and response states against what Outlook shows in the meeting's Tracking tab. Known gap: MeetingResponseStatus is what Exchange tracked, i.e. who accepted the invite, not who joined the Teams call. Actual attendance still comes from the absent lines you type (Teams attendance reports live in Teams, not in the calendar item; not reachable from COM).

4. Post metrics (5 min) — use a test meeting you organise, not the real stand-up

perl bin/cal.pl create --subject "COM test" --start 2026-09-23T16:00 --no-display
perl bin/cal.pl post "COM test" --text "hello from Perl"

Open the meeting in Outlook: body should contain the text. Then on a recurring meeting you own:

perl bin/cal.pl post "Alpha Stand-up" --file reports/2026-09-23-status.txt

Check only today's occurrence changed. Only then try --send once, on the test meeting, and confirm attendees get an update rather than a new invite.

5. Create (3 min)

perl bin/cal.pl create --subject "Charlie Stand-up" --start 2026-10-01T09:40 --attendee a@x.example --weekdays

The invite window should open with attendees and Mon–Fri recurrence; press the Teams Meeting button (or confirm it was added automatically), then Send or discard.

6. Wire into the rhythm (2 min)

scrum.conf: standup_match, team_from_subject (test: perl bin/daily.pl attend names the right team per meeting), attendance. Then the day is:

:SNew  →  daily.pl attend  →  stand-up, type notes  →  :SAll --draft  →  daily.pl post

Record

Paste results here: PS version, Outlook version, classic/new, what failed, what you changed.

7. Your AI service (5 min, after the calendar steps)

perl bin/daily.pl answers            # needs a pasted chat in standups/<date>-<Team>-chat.txt
perl bin/daily.pl ai                 # ai_backend = paste: writes reports/<date>-ai-prompt.txt

Paste the prompt into your AI service (check your organisation allows it for the data; a paste window is enough; an OpenAI-style endpoint works too), save the reply as reports/<date>-ai-response.txt, then perl bin/daily.pl report and confirm the "AI assessment" block appears. If the service exposes an OpenAI-style endpoint you are allowed to call, set ai_backend = curl, ai_url, ai_model, ai_key_env and re-run ai; add ai_curl_args = --cacert <your CA roots .pem> if curl rejects the certificate.

8. Cards, attendance download, joint block (10 min)

perl bin/daily.pl cards              # opens reports/<date>-cards.html; click one "send in Teams" link:
                                     # Teams must open a 1:1 chat with the card pre-filled. Press Enter to send.
perl bin/daily.pl cards --draft      # N Outlook drafts (one per member). Then once, on yourself only:
perl bin/daily.pl cards --send       # if Outlook shows "a program is trying to send e-mail", COM send is
                                     # policy-blocked here; use the Teams links or --draft.

After a real meeting: Attendance tab > Download, save to standups/<date>-attendance.csv,

perl bin/daily.pl joined             # join/leave/minutes per person; names mapped to teams

Check the report's separators/encoding survived (UTF-16 tab and UTF-8 comma are both handled); if names come out mangled, keep the file and adjust Attendance::decode_bytes.
