Halberd: a 12-week SysML v1 to v2 port, run on the agile kit

Halberd is fictional and notional, and so is every number here. Its legacy SysML v1 model holds 1,960 in-scope items across 7 organizations, and 1,450 DOORS requirements. One solutions architect ports it to SysML v2 text under a DevSecOps pipeline, one segment at a time, starting Monday 5 October 2026: two-week sprints, a baseline tagged every 4 weeks, a standup every working day, and the status meeting hears the alphabet — the 26 metrics A–Z of STATUS-METRICS.html. Thanksgiving and 24–25 December are holidays, so this is 56 working days.

This page is the public view. The project itself is a real kit project, built by compiling one stand-up file per day through the kit's own ledger (lib/Standup.pm, lib/Scrum.pm, lib/Ledger.pm); data/ is never committed, so rebuild it with one command:

perl sim/halberd-gen.pl                                   # data/halberd: journal, 56 stand-ups, answers; and this page
perl bin/ledger.pl -f data/halberd/scrum.txt bal Sprint:3   # the ledger: 330 items done in sprint 3
perl bin/scrum.pl  -f data/halberd/scrum.txt items done Halberd
perl agile.pl --today 2026-11-05 data/halberd              # the cockpit on a blocked day
perl bin/status-metrics.pl ...                             # the A-Z collector: see STATUS-METRICS.html, Appendix A

The metric dashboard, prefilled with Halberd's end-of-sprint-6 numbers, is STATUS-DASHBOARD.html; the weekly A–Z snapshot is Appendix C of STATUS-METRICS.html.

Funding and earned value

A notional FY27 funding journal sits beside the stand-up journal, in the same ledger format: data/halberd/funding.ledger. Each segment is budgeted at a notional $150 per v1 item, time-phased over the days the plan works it (~ Monthly from … to …); $323,400 is authorized on 1 October (budget at completion $294,000 plus a 10% reserve); labor posts weekly from the items actually ported, and sprint 3 overran while it waited on the shared runner. Percent complete comes from the stand-ups, so earned value is computed, not estimated.

perl bin/ledger.pl -f data/halberd/funding.ledger bal -M Expense --depth 3            # spend by month
perl bin/ledger.pl -f data/halberd/funding.ledger budget -M -b 2026-10-01 -e 2027-01-01 # budget vs actual by month
perl bin/ledger.pl -f data/halberd/funding.ledger evm --now 2026-11-30 --complete-file data/halberd/complete-2026-11-30.csv
perl bin/ledger.pl -f data/halberd/funding.ledger forecast --now 2026-11-30 --months 2 Assets   # when the money runs out
